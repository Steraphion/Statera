Informativa sulla privacy di Statera

Ultimo aggiornamento: 13 novembre 2026

In breve: Statera è un'app personale per registrare entrate e spese. I tuoi dati restano sul tuo dispositivo e, solo se attivi la sincronizzazione, nella cartella nascosta dell'app sul tuo Google Drive, cifrati con una password che conosci solo tu. Non esiste un server di Statera, non ci sono pubblicità, statistiche d'uso o servizi di terze parti.

1. Chi gestisce l'app

Statera è un progetto personale e non commerciale, pubblicato su GitHub Pages. Il codice sorgente è pubblico e consultabile su github.com/Steraphion/statera, dove è possibile anche inviare segnalazioni o domande.

2. Quali dati tratta l'app

  • Dati che inserisci tu: conti, carte (solo un nome scelto da te: il numero della carta non viene mai richiesto né salvato), categorie, movimenti con importi, date, descrizioni e note.
  • Dati del tuo account Google, solo se attivi la sincronizzazione: un'autorizzazione temporanea (token di accesso) che permette all'app di leggere e scrivere i propri file su Google Drive.

L'app non raccoglie posizione, contatti, identificativi pubblicitari, né dati di utilizzo.

3. Dove sono conservati

  • Sul tuo dispositivo, nella memoria del browser (IndexedDB). È la copia principale.
  • Sul tuo Google Drive, solo se attivi la sincronizzazione: in una cartella nascosta riservata a Statera (non visibile tra i tuoi file e non accessibile ad altre app). Il contenuto è cifrato sul dispositivo con AES-256-GCM, con una chiave derivata dalla tua password, prima di essere inviato: Google conserva il file ma non può leggerne il contenuto.
  • Nei file di backup che scegli di esportare tu: restano dove decidi di salvarli. Questi file non sono cifrati.

4. Accesso a Google Drive

Statera chiede un solo permesso: https://www.googleapis.com/auth/drive.appdata, cioè l'accesso alla propria cartella dati nascosta. L'app non può vedere, leggere o modificare nessun altro file del tuo Drive. Il token di accesso resta nel tuo browser e non viene inviato a nessun server diverso da quelli di Google.

L'uso e il trasferimento delle informazioni ricevute dalle API di Google rispettano le Norme relative ai dati utente dei servizi API di Google, inclusi i requisiti di utilizzo limitato (Limited Use). I dati non vengono mai venduti, condivisi, usati per pubblicità o per addestrare modelli di intelligenza artificiale.

5. Con chi sono condivisi

Con nessuno. L'unico servizio esterno coinvolto è Google, e solo per conservare il file cifrato della sincronizzazione sul tuo account. GitHub ospita esclusivamente il programma dell'app, non i tuoi dati.

6. Per quanto tempo

I dati restano finché li conservi tu. Puoi eliminarli in qualsiasi momento: dall'app (Altro → Elimina tutti i dati), cancellando i dati del sito nel browser, e per la copia su Drive da Google Drive → Impostazioni → Gestisci app → Statera → Elimina dati app nascosti.

7. Revocare l'accesso

Puoi revocare in qualsiasi momento l'accesso di Statera al tuo account Google dalla pagina myaccount.google.com/connections.
